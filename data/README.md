# Data notes

`segmentation/train.json` and `segmentation/val.json` are the fixed COCO-format annotation splits used in the manuscript.

`morphology/` contains image-level morphology extracted from the trained segmentation model for the 99 matched records.

`downstream/manuscript_analysis_dataset.csv` contains the composition, processing and recorded microstructural fields used in downstream analysis.

Raw SEM image files are not bundled here. Their redistribution status should be confirmed before public deposition.
