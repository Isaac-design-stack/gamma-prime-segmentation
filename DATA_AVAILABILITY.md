# Data and Code Availability

The code, annotations, trained-model artifacts, evaluation outputs, supporting processed data, and analysis resources associated with this research are archived on Zenodo at **https://doi.org/10.5281/zenodo.22663353**. The corresponding development repository is available on GitHub at **https://github.com/Isaac-design-stack/gamma-prime-segmentation**.

The experiments reported in the manuscript *“Automated γ′ Phase Segmentation in Nickel-based Superalloys Using Detectron2 for Materials Informatics”* were conducted using the original dataset of **99 SEM micrographs**, comprising **80 training images and 19 validation images**. Repository materials corresponding to the manuscript experiment are identified accordingly.

Following completion of the manuscript experiments, the dataset and annotation workflow underwent further development. This included the addition of **11 SEM micrographs**, resulting in an expanded working dataset of **110 images**, together with subsequent annotation, data-processing, and model-development work. The expanded workflow uses an **88/22 training-validation split**. These later materials are provided for transparency and continued research development and should not be interpreted as the dataset configuration used to generate the results reported in the manuscript.

Where original SEM micrographs originate from published third-party sources, redistribution is subject to the copyright and licensing terms of the original publications. Micrographs for which redistribution permission is not established are not intended for redistribution; their provenance should instead be documented through the repository source manifest and the corresponding citations to the original publications.

Users of this repository should refer to the dataset-version and reproducibility documentation to distinguish between the original manuscript experiment and subsequent expanded experiments.
